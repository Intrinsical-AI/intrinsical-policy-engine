# Boundaries

Intrinsical Policy Engine contains the core engine and an educational starter
pack only.

It does not include:

- regulatory packs;
- real policy calibrations;
- commercial evidence templates;
- sector-specific demos;
- generated real-world outputs;
- private repository history;
- legal advice;
- official guidance;
- certification logic;
- any guarantee of compliance.

The starter pack is illustrative. It exists to show how a pack is structured,
validated, exported, traced, and sealed.

## Provenance

This repository is a clean public distribution of the Intrinsical Policy Engine
core. It is derived from prior private development work, but intentionally
excludes private Git history, private framework packs, policy calibrations,
commercial templates, sector demos, generated outputs, and reserved assets.

This public boundary demonstrates the engine and the pack-authoring model
without publishing private regulatory or commercial content.
